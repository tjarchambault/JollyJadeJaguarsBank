# Personal Finance Tracker

## Project Description

Personal Finance Tracker is a modular Python project for recording and reviewing income and expenses. The application is being developed by a student team for ISTM 601.

## Project Phases

- Phase 1 - Project Proposal
- Phase 2 - Transaction Recording
- Phase 3 - Reporting and Exception Handling
- Phase 4 - User Interface and Final Integration

## Repository Structure

```text
data/       Starter CSV files for transactions and categories
docs/       Project reports, planning documents, and diagrams
images/     Generated visualization output
src/        Application modules and the main entry point
tests/      Starter tests for each feature module
```

## Running the Program

From the repository root, run:

```bash
python src/main.py
```

The application is currently a scaffold. Most functionality is planned or in development.

## Current Status

The initial modular repository structure and starter files are in place. Transaction entry, CSV persistence, validation, calculations, reports, command-line interaction, and visualizations are not implemented yet.

Future phases will add transaction recording, storage, category handling, validation, financial calculations, reports, exception handling, user interaction, visualizations, and final integration.
